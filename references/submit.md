# 5단계: 제출본 받기

사용자가 최종본을 주면 실행한다. 지시가 없으면 먼저 하지 않는다.

1. `04_지원기업/<폴더>/4_제출본_MMDD.md`에 **글자 그대로** 저장한다. `## 문항 N: 제목` 머리만 붙인다. 맞춤법도 고치지 않는다. 도구 없이 직접 쓴 문항도 같이 넣는다. 머리의 번호와 제목은 초안의 `## 문항 N: 제목`을 그대로 쓴다. 도구 없이 쓴 문항은 공고의 문항 번호를 쓴다.
2. 말투 기록을 쌓는다.

```
python3 .claude/skills/jaso/scripts/learn_style.py --application <폴더 이름> --final <제출본> --draft <3_초안> --log 01_나/말투_기록.md
```

   스크립트가 먼저 `비교:`, `초안에 없음:`, `제출본에 없음:` 줄로 무엇을 비교했는지 알린다. `제목이 초안과 다름` 경고가 있거나, 직접 쓰지 않은 문항이 `초안에 없음`으로 나오면 번호가 밀린 것이다. 머리를 고쳐 다시 실행한다(같은 지원서 기록은 덮어쓴다).
3. `새 숫자`가 나오면 고치지 않고 알린다. 사용자가 맞다고 하면 뱅크 장면의 `본인기억`에 `[본인 기억 MMDD]`로 저장한다. 제출본에 금지 표현이 있어도 알리기만 한다.
4. 새 기록 행을 읽고 `01_나/말투.md`를 갱신한다.
   - 머리의 `갱신:`, `샘플:` 줄을 고친다.
   - 처음 보는 패턴은 `## 후보`에 `- 패턴 (지원서 이름)`으로 적는다.
   - 서로 다른 지원서에서 2번 이상 나온 패턴은 `## 문체 특징`, `## 쓰는 표현`, `## 안 쓰는 표현`으로 올리고 후보에서 지운다.
   - `## 안 쓰는 표현`은 `- "표현"` 형식이다(check.py가 경고로 읽는다). 사용자가 지운 표현이어도 문맥상 지웠을 수 있으니 2번 이상 지웠을 때만 올린다.
   - 말투 근거는 말투_기록의 행뿐이다. 초안에서 그대로 남은 문장을 근거로 쓰지 않는다.
5. 무엇이 바뀌었는지 사용자에게 보여 준다. 틀리다고 하면 되돌린다.
6. `04_지원기업/_지원현황.md`의 해당 기업 상태를 제출로 고친다.
